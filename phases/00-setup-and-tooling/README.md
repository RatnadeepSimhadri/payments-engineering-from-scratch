# Phase 0: Setup & Tooling

> Three toolchains, one repository, zero magic.

8 lessons, 8 complete, ~7 hours. Generated from `curriculum/curriculum.json` by `scripts/build_catalog.py`.

## Start this phase

**First lesson:** [Dev Environment: Java 21, Python 3.12, Go 1.22](01-dev-environment/)

Run the first complete lesson from the repository root:

```bash
python3 scripts/run_lesson.py phases/00-setup-and-tooling/01-dev-environment --lang java
```

Keep the command, the exit code, and the test count as your first piece of evidence.

With an agent tutor: `/learn` (Claude Code), `learn` (Codex), or `Use learn to teach the next lesson.` The tutor reads your language from `LEARNING.md`.
